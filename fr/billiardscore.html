BilliardScore n'est plus activement maintenu. Vous pouvez toujours le télécharger et l'utiliser, mais il n'y aura plus de nouvelles mises à jour ni de nouvelles fonctionnalités.

Logiciel legacy pour clubs

BilliardScore - Front Office

BilliardScore est la partie front office de notre solution d'affichage : le logiciel que vous utilisez pendant les matchs pour afficher les scores et les résultats aux joueurs et au public.

Télécharger pour Windows Voir les vidéos
Front office Affichez les scores en direct pendant les entraînements, tournois et matchs.
Windows desktop Adapté aux installations de club déjà en place avec écrans et PC.
Avec BilliardAdmin Réutilisez directement les données de compétition pendant le match.

Fonctionnalités

Avec BilliardScore, vous avez notamment :

Tableau de match

  • Un tableau de score simple pour les entraînements et matchs amicaux
  • Un tableau de score pour les compétitions individuelles avec feuille de match
  • Un affichage clair pour les joueurs et le public

Équipes et réseau

  • Un tableau de score pour les compétitions par équipes avec feuille de match et récapitulatif
  • Plusieurs tableaux peuvent partager les données via le réseau
  • Pratique pour les installations fixes en club

Habillage club

  • La possibilité d'afficher vos propres bannières publicitaires
  • Compatible avec vos écrans existants
  • Idéal pour les clubs qui gardent leur organisation actuelle

Fonctionne avec BilliardAdmin

BilliardScore fonctionne très bien avec BilliardAdmin (back office). Utilisez BilliardAdmin pour préparer les compétitions, les listes de membres et les équipes, puis utilisez BilliardScore pour suivre le match en direct.

Disponible pour Windows comme logiciel legacy pour les clubs existants.

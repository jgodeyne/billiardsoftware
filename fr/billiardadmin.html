Avis de maintenance

BilliardAdmin n'est plus activement maintenu. Vous pouvez toujours le télécharger et l'utiliser, mais il n'y aura plus de nouvelles mises à jour ni de nouvelles fonctionnalités.

Logiciel legacy pour clubs

BilliardAdmin - Back Office

BilliardAdmin est la partie back office de notre solution d'affichage : le logiciel utilisé par les organisateurs pour préparer et gérer les compétitions.

Télécharger pour Windows Voir les vidéos
Back office Préparez compétitions, membres et équipes depuis un seul endroit.
Windows desktop Convient aux environnements de club avec postes fixes déjà en place.
Prêt pour le jour du match Envoyez directement vos données de compétition vers BilliardScore.

Fonctionnalités

Avec BilliardAdmin, vous pouvez notamment :

Membres et structure

  • Créer et gérer les fichiers membres
  • Garder une base claire pour l'administration du club
  • Pratique pour préparer une nouvelle saison

Gestion des compétitions

  • Configurer les compétitions individuelles
  • Mettre en place les compétitions par équipes
  • Gérer les règles et les paramètres des compétitions

Travaille avec BilliardScore

  • Préparer les données pour une utilisation dans BilliardScore
  • Passer facilement de la préparation à l'affichage du match
  • Idéal pour les clubs qui gardent leur organisation actuelle

Fonctionne avec BilliardScore

BilliardAdmin fonctionne très bien avec BilliardScore (front office). Vous préparez vos compétitions dans BilliardAdmin, puis vous réutilisez directement ces données dans BilliardScore pendant le match.

Télécharger BilliardAdmin

Disponible pour Windows comme logiciel legacy pour les clubs qui gardent leur installation actuelle.

  • BilliardAdmin pour Windows (version 2.3)
